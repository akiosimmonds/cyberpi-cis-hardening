# CyberPi CIS Hardening

A Raspberry Pi security hardening project documenting CIS-aligned configuration, validation, and evidence.

## Project Status

Repository setup is in progress. Hardening results and supporting evidence will be added as work is completed.

## Objective

Document a repeatable process for assessing a Raspberry Pi, applying selected security controls, and verifying the results.

## Planned Workflow

1. Record the hardware, operating system, and baseline configuration.
2. Identify the applicable CIS Benchmark and document its version and scope.
3. Assess selected controls and record initial findings.
4. Apply hardening changes with recovery steps.
5. Validate the changes and collect sanitized evidence.
6. Document results, exceptions, and lessons learned.

## Scope and Limitations

The Raspberry Pi model, operating system version, and benchmark selection are pending documentation. This project does not yet claim CIS compliance.

## Planned Documentation

- System inventory and baseline assessment
- Control checklist and benchmark references
- Hardening procedures and recovery steps
- Validation results and sanitized evidence
- Findings, exceptions, and lessons learned
